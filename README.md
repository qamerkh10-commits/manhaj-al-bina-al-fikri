# منهج البناء الفكري

خطة قراءة متكاملة في الفكر الإسلامي والعلوم الإنسانية والتراث، موزعة يومًا بيوم.

افتح `index.html` في المتصفح. التقدّم والإعدادات تُحفظ في المتصفح نفسه.

## بوت المتابعة على تيليجرام

بوت صارم يرسل ورد اليوم من الخطة نفسها كل صباح، ويطلب منك تأكيد كل مهمة، ويذكّرك حتى تتمّ الورد. ما لم يتم يصير دَينًا، وتنكسر سلسلتك، ويصلك تقرير أسبوعي كل جمعة. يعمل مجانًا على GitHub Actions كل ١٠ دقائق، وحالته مشفّرة في فرع `bot-data`.

التشغيل:
1. في تيليجرام افتح ‎@BotFather‎ وأرسل ‎/newbot‎، واختر اسمًا ومعرّفًا، وانسخ التوكن.
2. في هذا المستودع: Settings ← Secrets and variables ← Actions ← New repository secret، واجعل الاسم `TELEGRAM_TOKEN` والقيمة التوكن.
3. افتح البوت في تيليجرام وأرسل ‎/start‎ (أول من يرسلها يصبح صاحب البوت). يرد خلال دقائق.

الملفات: `bot/bot.mjs` (البوت)، و`bot/schedule.mjs` (يشغّل محرك الجدولة في index.html ليطابق التطبيق)، و`.github/workflows/bot.yml`.
