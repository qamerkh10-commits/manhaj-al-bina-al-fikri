# منهج البناء الفكري

خطة قراءة متكاملة في الفكر الإسلامي والعلوم الإنسانية والتراث، موزعة يومًا بيوم.

افتح `index.html` في المتصفح. التقدّم والإعدادات تُحفظ في المتصفح نفسه.

## صفحتان لشخصين

الصفحة الرئيسية تعرض اسمين، ولكل واحد صفحته: `khaled/` و`mohamed/`. لكل صفحة تقويمها (سنين الدراسة والامتياز)، وتقدّمها محفوظ على جهاز صاحبها باسم خاص بها، فلا تختلط الصفحتان على جهاز واحد. ومن الصفحة نفسها: تعديل الامتحانات، وشيل كتاب أو نقله أو إضافة كتاب. وزر «🤖 اربط البوت بصفحتك» يربط حساب تيليجرام بالصفحة.

## بوت المتابعة على تيليجرام

بوت صارم يرسل ورد اليوم من الخطة نفسها كل صباح، ويطلب تأكيد كل مهمة، ويذكّرك حتى تتمّ الورد. ما لم يتم يصير دَينًا وتنكسر سلسلتك، ويصلك تقرير أسبوعي كل جمعة. وفيه قناة للملخصات: تختار الكتاب («📚 اختر كتابًا») وترسل الريكورد، فيُنشر بهاشتاج الكتاب ويُحدَّث فهرس مثبّت.

**كيف يعمل:**
- `worker/`: البوت نفسه على Cloudflare Workers (مجاني)، يرد فورًا عبر webhook، وساعة كل ٥ دقائق للتذكيرات، وحالته في Durable Object.
- `bot/core.mjs`: منطق البوت كله، مستقل عن مكان التشغيل.
- `bot/sync.mjs` و`.github/workflows/sync.yml`: كل ساعة يحسب GitHub الجدول من `index.html` نفسه (`bot/schedule.mjs`)، ويرسله للبوت، ويسلّمه التوكن.

**الإعداد:** التوكن سرّ واحد في المستودع (`TELEGRAM_TOKEN`)، وعنوان البوت متغيّر (`WORKER_URL`). والنشر: `cd worker && npx wrangler deploy`.
